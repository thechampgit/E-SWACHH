# **App Name**: CivicPulse

## Core Features:

- AI Severity Assessment Tool: Uses AI to analyze uploaded photos and descriptions to suggest priority levels and appropriate maintenance categories automatically.
- Live Issue Reporting: Citizens can submit civic reports including photo uploads via Firebase Storage and geo-tagging, stored in Firestore.
- Status Timeline Tracker: A real-time visual progress bar and timeline that updates as administrative staff change report statuses from Pending to Resolved.
- Impact Map Visualizer: An interactive Google Maps integration displaying clusters of reported issues and highlighting successful resolutions in the community.
- Admin Management Console: A comprehensive dashboard for authorized users to manage reports, filter by category, and update resolution statuses in bulk.
- Secure Role-Based Access: Multi-tier authentication for Citizens and Admins using Firebase Authentication to protect user data and administrative actions.
- Unified Citizen Inbox: A centralized notification hub where users receive real-time alerts for updates on their specific civic reports.

## Style Guidelines:

- The primary color is a deep, trustworthy Navy Blue (#3058B3) reflecting civic stability and professional reliability.
- The background uses a pristine, lightly tinted Cool White (#F9FAFB) to maintain clarity and focus.
- The accent color is a vibrant Cyan (#22A0C2), providing an energetic contrast for active reporting and positive resolution feedback.
- Font pairing: 'Inter' for bold, machined headlines conveying objectivity; 'PT Sans' for body text to add a touch of humanist warmth to communication.
- Geometric line icons with varying weights, emphasizing precision and urban architecture elements.
- A clean, card-based responsive layout with generous white space and high-contrast borders for accessibility on mobile devices.
- Subtle slide-and-fade micro-interactions for dashboard widgets and smooth transitions between report states.
